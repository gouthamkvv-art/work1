## 🛠️ Tech Stack

- **Framework:** React 19 + Vite 6
- **Styling:** Tailwind CSS v4 with custom `@theme` variables
- **Icons:** Lucide React + custom SVG icons
- **Fonts:** Cinzel (Royal Display), Cormorant Garamond (Editorial Serif), Plus Jakarta Sans (Modern Body)

---

## 🚀 Running the Project

### Development
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```

## ⚙️ How to Update Business Information

All verified company details, phone numbers, WhatsApp links, services, dishes, and gallery photos are centralized in:
`src/data/siteData.js`

To update the WhatsApp number or address in the future, simply edit `COMPANY_INFO` in `src/data/siteData.js`.
